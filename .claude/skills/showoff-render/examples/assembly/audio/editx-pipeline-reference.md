# Step-Audio-EditX pipeline — reference

How the v5–v7.2 narration was built. **EditX is no longer used by this film** — v8 replaced it with
Kokoro generating directly, after the listener ranked EditX's raw conditioning prompt above every
clone of it. This file is kept so v7.2, still the approved cut, remains reproducible.

Lifted verbatim out of [`VOICE-LOG.md`](VOICE-LOG.md) when that log hit its size ceiling. The
scripts it describes are in [`pipeline/`](pipeline/) and ⚠ **still point at
`%TEMP%\temperature-controller-media\` and `PCB\render\`, both dead since session 58.**

## End-to-end

1. **Env**: copy `chatterbox-venv` → `editx-venv` (saves the 2.5 GB CUDA torch download; venv
   copies work if you only call `python.exe` directly). Then
   `pip install transformers==4.53.3 accelerate sentencepiece omegaconf hyperpyyaml protobuf onnxruntime openai-whisper`.
2. **Code**: `git clone --depth 1 Saganaki22/ComfyUI-Step_Audio_EditX_TTS`; use
   `step_audio_impl/` directly (chdir there, `sys.path.insert`) — no ComfyUI. Key API:
   `StepAudioTokenizer(tok_dir, model_source=LOCAL)`, `StepAudioTTS(model_dir, encoder)`,
   `engine.clone(prompt_wav, prompt_text, target_text)` and
   `engine.edit(wav, text, "paralinguistic", "", text_with_[breath]_tags)`, both → `(audio, sr)`.
3. **Models**: `snapshot_download` of `stepfun-ai/Step-Audio-Tokenizer` and
   `stepfun-ai/Step-Audio-EditX` into `%TEMP%\editx-models\` (9.1 GB total).
4. **Voice identity**: the clone prompt is `onyx_prompt.wav` — 9.75 s of Kokoro `am_onyx` reading
   a neutral passage (generated by `gen_prompt.py`). Synthetic speaker, so deep timbre without
   using any real person's voice.
5. **Generation** (`editx_gen.py`): model loaded once; 4 clone takes per line (seeded); every take
   trimmed (librosa split, 40 dB, 60 ms pad) and transcribed by openai-whisper base.en; WER > 0.05
   rejected; best = duration closest to target, slower on ties. Lines containing "..." then get one
   paralinguistic pass inserting `[breath]` at the ellipses — kept only if WER ≤ 0.08 and it still
   fits the slot cap, else the plain clone ships.
   🔴 That trim is the step `natural-voice/EXPERIMENTS.md` lists as rejected, and v8 removed it.
6. **Mix** (`mix_final.py <takes-dir> <out.mp4>`): per line measure integrated loudness
   (ffmpeg loudnorm print_format=json) → static gain to −16 LUFS → adelay to its start; music
   ducked via `sidechaincompress` (thr 0.02, ratio 6, atk 150 ms, rel 900 ms); sum limited
   (alimiter 0.97); two-pass **linear** loudnorm to −14 LUFS / −1 dBTP; mux `-c:v copy` + AAC 256k;
   MD5-verify the video stream.
7. **Previews**: 2 audio-only m4a cuts (opening, ending) so the voice can be judged in seconds.

## Pitfalls

- **ffmpeg is not on PATH here** — it broke `transformers` ASR *and* `openai-whisper`
  (`FileNotFoundError` deep in a worker). Fix in-script:
  `os.environ["PATH"] += os.pathsep + r"...\Gyan.FFmpeg...\bin"`.
- **pip on this venv pulled CPU torch** for chatterbox; reinstall
  `torch==2.6.0 torchaudio==2.6.0 --index-url .../whl/cu124` or the 4080 idles.
- **transformers conflict**: chatterbox-tts pins 5.2.0, EditX port pins 4.53.3 → separate venvs
  (copy, don't rebuild).
- **Don't let per-take selection mix voices** (first kokoro run chose am_michael for 3 lines and
  am_onyx for the other — two narrators). Lock the voice, vary only pacing/seed.
- **Inline python via PowerShell breaks on backslash paths** ($env: expansion inside the source);
  always write a script file.
- **Kokoro naming**: `KPipeline(lang_code="a")`, voice `am_onyx`; output 24 kHz chunks to concat.
- Chatterbox venv install log is gone but the recipe is: py 3.12 venv, `pip install chatterbox-tts`,
  then the cu124 torch swap above.
