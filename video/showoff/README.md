# Showoff films

Hardware shot like it matters — no diagrams, no explaining, just the object. One so far.

| | what it is |
|---|---|
| [`assembly/`](assembly/) | the board building itself, part by part, straight off `PCB_new.kicad_pcb` |

## Why a bucket holding one film

The directory was named for a genre and then built as that single film, so a second hero film had
nowhere to sit that was not already this one's `picture/`, `audio/` and `script/`. Splitting it now
costs a path rewrite; splitting it later costs that plus untangling two films. `education/` was
split for the same reason. Which films leave with `video/` is settled in
[`../README.md`](../README.md), not here.

## Before a second one

The picture is the expensive half and the CAD is the half that goes wrong. GATE 0 of
[`showoff-render`](../../.claude/skills/showoff-render/SKILL.md) is a hard stop — no rendering
until every model is real, complete and frozen — and [`assembly/RENDER-LOG.md`](assembly/RENDER-LOG.md) is the evidence it was written
from: a wrong colour in a *model* sent one reproduction hunt through both Blender versions and two
board revisions first.

The finished cuts stayed with the project that made them. What is here is how to make the next one.
